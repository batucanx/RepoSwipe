Privacy Policy for RepoSwipe

Last updated: September 5, 2026

RepoSwipe is a personal, open-source Android app for discovering GitHub repositories with a swipe-based interface. This page explains what data the app interacts with, where it goes, and what control you have over it.

Signing in with GitHub

RepoSwipe uses Firebase Authentication's GitHub sign-in to let you log in with your existing GitHub account. During sign-in, GitHub asks you to approve a limited set of permissions (repository access and follow/unfollow), and RepoSwipe receives a GitHub access token in return.

  • That token is stored only on your device, encrypted using Android's Keystore-backed secure storage. RepoSwipe has no backend server of its own and never transmits your token anywhere.
  • The token is used exclusively to call GitHub's own API on your behalf — browsing repositories, starring/unstarring, and following/unfollowing users — directly from your device to GitHub.
  • Signing out (Settings → Sign Out) deletes the token from your device. You can also fully revoke RepoSwipe's access at any time from github.com/settings/applications.

The "Trending Today" leaderboard

When you swipe right (star) or left (pass) on a repository, RepoSwipe records one anonymous, aggregate entry in a shared Cloud Firestore database: the repository's id, name, owner, description, language, GitHub URL, a running swipe count, and a timestamp. This powers the in-app leaderboard of repositories trending across all RepoSwipe users that day.

This record is not linked to your identity, account, or GitHub username in any way — it only describes the repository being swiped on, not who swiped on it.

Crash and performance monitoring

RepoSwipe uses Sentry to catch crashes and performance issues so they can be fixed. If the app crashes or encounters an error, Sentry automatically receives basic diagnostic information: device model, OS version, app version, and a stack trace of the error. RepoSwipe does not deliberately attach your GitHub identity or any personal profile data to these reports.

What RepoSwipe does not do

  • No advertising, no ad tracking, no behavioral profiling.
  • No sale or sharing of your data with third parties for marketing purposes.
  • No RepoSwipe-operated backend server — the app talks directly to GitHub's API, and to Firebase (Google) for sign-in and the leaderboard described above.

Third-party services

RepoSwipe relies on the following third-party services, each governed by its own privacy policy:

  • GitHub — sign-in and repository data
  • Firebase (Google) — authentication and the trending leaderboard database
  • Sentry — crash and performance monitoring

Children's privacy

RepoSwipe is not directed at children under 13, and does not knowingly collect data from children.

Changes to this policy

This page may be updated as the app changes. The full history of edits is publicly visible in the app's GitHub commit history.

Contact

Questions about this policy or your data can be raised as an issue on the RepoSwipe GitHub repository.
